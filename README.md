## 🚀 Proyectos Destacados

### Sistema de Inscripción FES Acatlán
Este es el proyecto principal que estoy documentando mediante iteraciones (Sprints). Se trata de un sistema que optimiza el proceso de inscripción y asignación de grupos para los alumnos, validando requisitos de seriación, promedios y cupos en tiempo real.

**¿Qué encontrarás en esta sección?**
- 📝 **Diccionario de Datos (Especificación Estructurada):** Definición formal de las entidades del sistema (Alumno, Grupo, Credenciales, etc.), sus atributos, reglas de negocio y restricciones.
- 📊 **Diagramas de Flujo de Datos (DFD):** Modelado del sistema estructurado por niveles (Nivel 0, Nivel 1 y desgloses de Nivel 2) con una correcta jerarquía y balanceo de datos.
- 💻 **Prototipos UI (Sprints 1, 2 y 3):** Maquetación de la interfaz gráfica desarrollada en HTML, Tailwind CSS y JavaScript para validar la experiencia de usuario y el flujo de los procesos.

## 🛠️ Tecnologías y Herramientas Utilizadas

A lo largo de este repositorio, aplico diferentes herramientas para el diseño y desarrollo de software:

- **Modelado y Documentación:** Markdown, Mermaid.js (para DFDs y arquitectura).
- **Prototipado Frontend:** HTML5, CSS3 (Tailwind CSS), JavaScript (Vanilla).
- **Metodologías:** Ingeniería de Requerimientos (Método VOLERE), Análisis Estructurado de Sistemas, Metodología de Desarrollo Ágil (Sprints).
